# AI Infra SRE 面试题库

> 基于腾讯/字节/华为官方 JD + 行业高频题整理

## 一、系统设计题

### 1. 大规模 GPU 集群监控与告警体系设计
**考察点**：GPU 利用率/显存/温度监控、告警降噪、故障自动切换
**你的答题框架**：
- 指标采集：DCGM Exporter + Prometheus + Grafana
- 告警治理：分级告警（P0-P3）、告警聚合、智能降噪
- 故障响应：自动 failover → 人工介入 → 根因复盘
**你的实战支撑**：工单智能体的故障案例结构化沉淀

### 2. K8s 调度策略 + AI 训练任务资源优化
**考察点**：Volcano/Kueue 调度、GPU 共享、弹性伸缩
**你的答题框架**：
- 调度策略：Gang Scheduling + Priority + Preemption
- GPU 优化：MPS/MIG 共享、time-slicing
- 成本优化：Spot 实例 + 混合调度 + 利用率监控
**你的实战支撑**：ACK 产品工单 + 专有云 AI Stack

### 3. LLM 推理服务架构设计
**考察点**：vLLM/TensorRT-LLM、P/D 分离、KV Cache 优化
**你的答题框架**：
- 推理引擎：vLLM PagedAttention + Continuous Batching
- 架构模式：PD 分离（Prefill + Decode 分离部署）
- 优化手段：KV Cache 量化、Speculative Decoding、Flash Attention
**补课重点**：建议实操 vLLM 部署一个 7B 模型

## 二、故障排查题

### 4. 描述一个复杂线上故障的定位与恢复
**STAR 模板**：
- **S**：K8s 集群某节点 Pod 大面积 CrashLoopBackOff
- **T**：需在 30 分钟内恢复服务
- **A**：kubectl describe → events 分析 → 定位 OOM → 调整 limits → 滚动重启
- **R**：MTTR 从 2h 降至 15min，建立故障案例库

### 5. GPU 服务器宕机后的推理服务恢复
**考察点**：故障检测 → 流量切换 → 数据恢复 → 根因分析
**答题框架**：
- 检测：健康检查 + 心跳超时
- 切换：Load Balancer 自动摘除故障节点
- 恢复：新节点启动 + 模型加载 + 流量回切
- 复盘：硬件巡检 + 驱动版本 + 散热环境

## 三、概念理解题

### 6. SRE "错误预算"的理解与实践
- 错误预算 = 1 - SLO（如 99.9% 可用性 → 0.1% 错误预算）
- 预算充足：可推进变更/发布
- 预算耗尽：冻结变更，优先稳定性
- 你的实践：工单智能体的 SLA 跟踪

### 7. AIOps vs Agentic 运维的区别
- AIOps：基于规则/ML 的告警分析、异常检测
- Agentic 运维：Agent + Skills 工具化，自主决策+执行
- 你的优势：有真正的 Agent 落地经验（多数 SRE 没有）

### 8. LLMOps 的核心挑战
- 模型版本管理 + 数据漂移检测
- 推理成本优化（GPU 利用率 vs 延迟 vs 吞吐）
- 评估体系（自动化评测 + 人工标注）
