## 关于这些清单的可信度

各文件的「数据来源」行已注明出处（深圳发改委、21 经济网、新华网、胡润研究院、福布斯中国、各公司官网等）。
阅读时请注意：

- **公司官网提供的数据未经独立核实**，属于公司自述。
- **榜单数字存在口径差异**，例如深圳独角兽数量胡润计 44 家、GEI 报告计 47 家——差异本身写进了文首，未强行取一个数。
- **公司状态变化快**。本目录时间戳为 2026 年 9 月，融资/上市信息此后可能已失效。
- 需要判断某一家具体公司时，请按 [赛道研究/README.md](../赛道研究/README.md) 的调研规范单独成文，不要直接采信这里的单行摘要。

## 维护约定

- 新增公司：归入对应赛道文件，字段与既有条目保持一致（公司 / 成立 / 产品 / 融资 / 来源）。
- 同一公司在两个文件里都出现时，**只在主赛道文件保留完整条目**，另一处用链接引用。
- 结构性研究（赛道格局、政策脉络）可单独成文，放在本目录根下。
